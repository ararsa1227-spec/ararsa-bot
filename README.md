# Technology Solution Telegram Bot

Professional Telegram customer-service bot built with Python, aiogram 3, FastAPI and Render webhook deployment.

## Render settings

Build Command:
`pip install -r requirements.txt`

Start Command:
`python bot.py`

Instance:
Free is enough for initial testing.

## Environment variables

BOT_TOKEN = token from @BotFather

ADMIN_ID = your Telegram numeric user ID

WEBHOOK_URL = your Render HTTPS service URL, for example:
https://technology-solution-bot.onrender.com

Do not include `/telegram/webhook` in WEBHOOK_URL.

## Features

- Professional home menu
- IT service catalogue
- Service requests
- Quote requests
- Product information
- Customer message forwarding to admin
- Photo/attachment notification
- Health endpoint
- Render-compatible webhook
- Ready for multilingual expansion
